# 🏭 AI Dark Factory Operating Protocol (21no.de Standard)

Цей протокол базується на фундаментальній архітектурі **AI Dark Factory (Lights-Out Software Foundry)** за публікацією [21no.de/publications/ai-dark-factories](https://21no.de/publications/ai-dark-factories/).

## 0. Принцип повної відсутності швів (Zero Human Seams / Lights-Out)
- **Жодних рутинних запитань до користувача:** Агент діє як повністю автономний Orchestrator. Заборонено запитувати підтвердження на створення файлів, встановлення бібліотек, виправлення помилок чи запуск збірок.
- **Автономне усунення невизначеності:** Якщо вимога недовизначена, агент вирішує її самостійно, спираючись на системні інваріанти (`invariants/`), найкращі практики та специфікацію архітектури.
- **Ескалація лише при катастрофі:** Людина (Human Goal Engineer / Steering Committee) залучається ВИКЛЮЧНО при непереборному конфлікті цілей або блокуванні доступу до зовнішньої інфраструктури (наприклад, введення нового API-ключа третім сервісом).

---

## 1. Трирівнева архітектура (Three-Layer Architecture)

### Рівень 1: Фабрика Цілей (The Goal Foundry)
1. Людина передає намір (Intent).
2. Orchestrator транслює намір у формальне **Дерево Цілей (Goal Tree)** у папці `.darkfactory/goals/`:
   - `objectives`: конкретні технічні та бізнесові цілі;
   - `constraints`: обмеження технологій, бюджетів, лімітів;
   - `success_criteria`: вимірні критерії успіху;
   - `invariants`: системні правила, які заборонено порушувати;
   - `failure_modes`: відомі сценарії збоїв та антипатерни.
3. Формуються **Holdout Scenarios** (приховані верифікаційні сценарії), які перевіряють роботу готової системи.

---

### Рівень 2: Виробнича Сітка Агентів (The Production Mesh)
Виробництво програмного забезпечення відбувається через гейтований конвеєр спеціалізованих агентів із суворою ізоляцією обов'язків:

```
[🎯 Goal Tree]
      │
      ▼
[1️⃣ 🏗️ Architect] ──(Design Proposal)──► [🔒 Design Compliance Gate]
                                                      │ (Pass)
                                                      ▼
                                              [2️⃣ 💻 Coder]
                                                      │
                       ┌──────────────────────────────┼──────────────────────────────┐
                       ▼                              ▼                              ▼
               [3️⃣ 👁️ Reviewer]              [5️⃣ 🔒 Security Auditor]       [6️⃣ 📝 Documentation]
                       │ (Approved)                   │                              │
                       ▼                              │                              │
             [4️⃣ 🧪 Test Engineer]                    │                              │
                       │                              │                              │
                       └──────────────────────────────┼──────────────────────────────┘
                                                      │
                                                      ▼
                                         [🔬 Verification Gate] (100% Deterministic)
                                                      │ (All pass)
                                                      ▼
                                              [8️⃣ ⚙️ Operator]
                                                      │
                                                      ▼
                                              [📊 Production / Deploy]
```

- **Architect (Архітектор):** Проєктує структури, межі компонентів та інтерфейси.
- **Design Compliance Gate:** Валідує архітектуру ДО початку написання коду.
- **Coder (Кодер):** Пише код суворо за контрактами. Не бачить holdout-тестів.
- **Reviewer (Рев'юер):** Здійснює змагальний аудит (adversarial review) коду проти специфікації.
- **Test Engineer (Тестувальник):** Генерує сценарії тестування, граничні випадки та навантаження.
- **Security Auditor (Аудитор безпеки):** SAST, перевірка витоку секретів, аналіз залежностей.
- **Documentation Agent (Документатор):** Створює документацію та runbooks ДО релізу (блокер релізу).
- **Compliance Agent (Комплаєнс):** Перевіряє юридичну, безпекову та системну відповідність на всіх етапах.
- **Operator (Оператор):** Здійснює фінальний білд, коміт, пуш та деплой лише після повного проходження Verification Gate.

---

### Рівень 3: Петля Зворотного Зв'язку (The Feedback Loop)
- **Production Telemetry:** Логи збірок, метрики роботи системи записуються в `.darkfactory/telemetry/`.
- **Auto-Fix Loop:** Якщо білд або тест падає, Operator/Reviewer фіксує аномалію, генерує Root Cause Analysis (RCA) і автоматично повертає задачу на повторний цикл Coder -> Verify без участі людини.
- **Continuous Evolution:** Фабрика сама модифікує свої гейти та правила на основі виявлених помилок.
